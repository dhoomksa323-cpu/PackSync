# PackSync — Forge 1.20.1

## السيرفر
1. حط `packsync-1.0.0.jar` في `mods` حق السيرفر وشغّله.
2. افتح البورت **8100**.

خلاص. المود ياخذ مودات وإعدادات السيرفر ويرسلها للاعبين تلقائياً، وكل ما تغيّر شي ينشر التحديث لحاله.
(مودات للاعبين بس مثل الشيدرز والخرائط؟ حطها في `packsync/pack/mods/`)

## اللاعب
- أول مرة: يحمّل المودباك من `http://IP-السيرفر:8100/` ويفكه في مجلد النسخة.
- بعدها: يدخل السيرفر ← إذا نسخته قديمة يطلع زر **تثبيت التحديث** ← يضغطه ← اللعبة تتحدث وترجع تدخله السيرفر.
